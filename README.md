# The Bits and Gears Show

A website I created to pitch **The Bits and Gears Show**, a proposed inter-house technology quiz competition for students in Classes IX–XII at my school.

The project presents the event idea, explains how the competition would work, and brings the key information into one place for school staff and prospective participants.

## The idea

The Bits and Gears Show was planned to make learning about technology engaging through friendly competition. The proposed event encourages digital literacy, critical thinking, teamwork, and quick problem-solving, with students competing in teams of two for their school houses.

The website includes the original proposal's October 2025 schedule and school auditorium venue. These details document the pitch; they do not confirm that the event took place.

## Proposed competition rounds

1. **Tech IQ** — Multiple-choice questions covering core technology concepts, terminology, and general knowledge.
2. **Fact or Fiction** — True-or-false questions about technology statements, myths, and trends.
3. **The Buzzer Blitz** — Advanced questions that reward technical knowledge and quick recall.
4. **The Bonus Lens** — Bonus questions based on images, video, or audio featuring technology personalities, products, and events.

## What the website includes

- An introduction to the event and its learning goals.
- Interactive tabs explaining the four quiz rounds.
- Profiles of the founding and hosting team.
- Proposed awards and participation certificates.
- Registration instructions through the teacher-in-charge.
- Contact information and a social media link.
- A responsive layout with mobile navigation, animated backgrounds, and glass-style cards.

## Built with

- **HTML5** for page structure.
- **Tailwind CSS via CDN** and custom CSS for styling and animation.
- **Vanilla JavaScript** for round tabs and mobile navigation.
- **Google Fonts** for typography.
- **Vercel Analytics** script integration for deployments on Vercel.

## View locally

Open `index.html` in your browser, or serve the project folder with a static web server such as VS Code's Live Server extension.

No build step or dependency installation is required to view the page. An internet connection is needed to load Tailwind CSS and Google Fonts from their external providers.
